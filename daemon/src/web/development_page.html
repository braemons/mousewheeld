mousewheeld

This page stands in for the console: it mounts the panels this daemon serves and holds no logic of its own, which is the point of the /elements/ contract. A real console imports /elements/mousewheeld.js from here and lays the same panels out beside another daemon's. The API this is all talking to is authored at /api/proto — the .proto files themselves, which is where its types and its behaviours are written down.
